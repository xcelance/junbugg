## 2. Payout Settings Section

### Stripe Connect

| Element | Description |
|---------|-------------|
| **Connect with Stripe** button | Starts Stripe Express onboarding |
| **Status badge** | Active / Pending / Requirements Due / Disabled |
| **Disconnect** link | Removes your Stripe account |
| **Refresh Status** link | Re-checks Stripe for updates |

### Donations Toggle

| Toggle | Effect |
|--------|--------|
| **ON** | Fans can donate on your profile page |
| **OFF** | Donate section is hidden |

### Donation Stats

- **Total Received** — Sum of all completed donations
- **Pending** — Payments being processed

---

## 3. Fan Clubs Section

*Visible if fan club plans are created for you.*

| Element | Description |
|---------|-------------|
| **Active Subscribers** | Number of current paying members |
| **Monthly Revenue** | Total recurring subscription revenue |
| **Plans** | List of your fan club tiers and prices |

---

## 4. Paid Events Section

*Visible if events are created for you.*

| Element | Description |
|---------|-------------|
| **Upcoming Events** | Events coming soon |
| **Past Events** | Events that have ended |
| **Tickets Sold** | Total tickets across all events |
| **Revenue** | Total event revenue |

---

## 5. Common Actions

| Action | How To |
|--------|--------|
| Connect Stripe | Click **Connect with Stripe** in Payout Settings |
| Enable donations | Toggle **Donations** to ON |
| Check payout status | Look at **Stripe Account** badge |
| View donation history | Check **Total Received** or Stripe Express |
| Create fan club | Contact site administrator |
| Create paid event | Contact site administrator |

---

## 6. Dashboard Tips

- ✅ **Refresh** the page after connecting Stripe to see updated status
- ✅ **Enable donations** immediately after connecting Stripe
- ✅ Check your **Stripe Express** dashboard regularly for any requirements
- ❌ Don't close the Stripe onboarding window before completing it
