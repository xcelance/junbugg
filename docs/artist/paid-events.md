# Artist Guide — Paid Events

> **For:** Artists on JunBugg  
> **Covers:** Setting up paid events, ticket sales, and access

---

## 1. What Are Paid Events?

Paid events let you sell **one-time tickets** for:

- 🎵 Listening parties
- 🎤 Live performances (virtual)
- 📹 Exclusive content premieres
- 🎓 Workshops & classes
- 🎮 Gaming sessions

Each ticket is a one-time purchase — no recurring fees.

---

## 2. Create a Paid Event

Events are created by the site administrator. Contact them with:

| Detail | Example |
|--------|---------|
| **Event Name** | "Live Listening Party — New Album" |
| **Description** | "Join me for an exclusive first listen..." |
| **Date & Time** | June 30, 2026 — 8:00 PM EST |
| **Ticket Price** | $5.00 |
| **Max Attendees** | 50 |
| **Event Link** | Zoom/YouTube link for attendees |

## 3. How Fans Buy Tickets

1. Fan finds your event on your profile or events page
2. Clicks **Buy Ticket** or **Get Access**
3. Pays the ticket price via Stripe
4. Receives event access details (link, password, etc.)
5. Attends the event at the scheduled time

---

## 4. Manage Event Attendees

Your dashboard or the site admin can show:

- **Number of tickets sold**
- **Total revenue from the event**
- **Attendee list** (names/emails)
- **Revenue after fees**

## 6. Frequently Asked Questions

**Q: Can I set up recurring events (e.g., monthly)?**  
A: Yes — each event is created separately. Contact the admin.

**Q: What if an event is cancelled?**  
A: All ticket holders should be refunded. Contact the site administrator.

**Q: Can I set a minimum price?**  
A: The ticket price is set when the event is created.

**Q: Do attendees get refunds?**  
A: Refunds are handled by the site administrator on a case-by-case basis.
